# 🖨️ Tlačové hárky pre fyzický útok (Canon PIXMA TS3450, 300 DPI)

Tento priečinok obsahuje všetky pripravené tlačové hárky formátu A4. Všetky hárky sú kalibrované na presné fyzické rozmery v milimetroch pri rozlíšení **300 DPI**.

---

## ⚠️ DÔLEŽITÉ POKYNY PRE TLAČ (Canon PIXMA TS3450):
1. **Mierka tlače**: V dialógu tlače (Adobe Acrobat / prehliadač) VŽDY zvoľte **„Skutočná veľkosť“ (Actual Size / 100 %)**.
   * ❌ Nikdy nevoľte „Prispôsobiť veľkosti papiera“ (Fit to page), inak sa rozmery náplastí zmenšia o 4–7 %!
2. **Typ papiera**: Obyčajný kancelársky papier 80 g/m² (Plain Paper).
3. **Tlač bez čiernej kazety (iba farebná CL-546)**:
   * V nastaveniach tlačiarne zvoľte: `Údržba -> Nastavenie atramentovej kazety -> Iba farebná (Color Only)`.
   * Tlačiareň namieša tmavé pásky cez kompozitné CMY (azúrová + purpurová + žltá).
